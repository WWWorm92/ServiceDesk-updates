# ServiceDesk

**Внутренний сервис поддержки с установщиком для Windows и интерфейсом в браузере.**

Заявки сотрудников, учёт оборудования, командный и личный чат, заметки, Telegram-уведомления и резервные копии в одном приложении.

[Скачать для Windows](https://github.com/WWWorm92/ServiceDesk-updates/releases/latest) · [История выпусков](https://github.com/WWWorm92/ServiceDesk-updates/releases) · [Сообщить о проблеме](https://github.com/WWWorm92/ServiceDesk-updates/issues)

## Возможности

- Заявки с фотографиями, комментариями, статусами и исполнителями.
- Поиск и фильтры по заявкам.
- Учёт оборудования и история изменений.
- Общий чат и личные диалоги сотрудников.
- Личные заметки.
- Telegram-уведомления с фоновой очередью отправки.
- Пользователи и права администратора.
- Резервное копирование и восстановление данных.
- Проверка и установка обновлений из интерфейса администратора.
- Русский интерфейс, светлая и тёмная темы.

## Требования

- Windows 10/11 x64.
- Браузер для работы с интерфейсом.
- Свободный локальный порт, по умолчанию `5000`.

Python и зависимости включены в установщик. Интернет для установки и обычной локальной работы не требуется; он нужен для Telegram и проверки обновлений.

## Установка

1. Откройте [последний релиз](https://github.com/WWWorm92/ServiceDesk-updates/releases/latest).
2. Скачайте файл `ServiceDesk-<версия>-Windows-x64-Setup.exe`.
3. Запустите установщик **от обычного пользователя, не от имени администратора**.
4. Выберите порт, ярлыки и автозапуск.
5. При первой установке создайте администратора с паролем от 10 символов.
6. После запуска откройте `http://127.0.0.1:5000` или адрес с выбранным портом.

Для ZIP-варианта полностью распакуйте архив и запустите `Install.cmd`.

Установщик не подписан цифровой подписью. Для проверки файла используйте `SHA256SUMS.txt` из того же релиза; не отключайте защиту Windows или правила организации.

## Данные и автозапуск

| Что | Где / как работает |
| --- | --- |
| Программа | `%LOCALAPPDATA%\Programs\ServiceDesk` |
| База, фотографии, настройки и журналы | `%LOCALAPPDATA%\ServiceDesk\data` |
| Адрес по умолчанию | `http://127.0.0.1:5000` |
| Автозапуск | При входе текущего пользователя в Windows |

Автозапуск не является системной службой: до входа пользователя сервер не работает. Данные хранятся отдельно от программы и сохраняются при штатном обновлении и удалении.

По умолчанию приложение доступно только на этом компьютере. Доступ по сети настраивает администратор: адрес прослушивания, firewall и защищённый reverse proxy или VPN.

## Обновление и резервная копия

В приложении откройте **Система → Обновления**. Проверка новых выпусков выполняется при старте и каждые 6 часов; установку запускает администратор.

Перед обновлением или переносом сохраните резервную копию через раздел **Система**. Для ручного обновления запустите новый установщик под той же учётной записью Windows.

При переносе на другой компьютер установите ServiceDesk, создайте временного администратора и восстановите резервную копию. После восстановления используйте прежнюю учётную запись.

## Поддержка

Создавая [issue](https://github.com/WWWorm92/ServiceDesk-updates/issues), укажите версию ServiceDesk, версию Windows и шаги воспроизведения. Приложите нужный фрагмент `launcher.log` или `app.log`, удалив токены, пароли и данные сотрудников.

Этот репозиторий содержит публичные установщики и сведения о выпусках. Исходный код приложения здесь не размещается.
